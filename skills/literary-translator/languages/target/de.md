# German as the target language (`de`)

> Status: first draft. Native review welcome (see CONTRIBUTING.md).

Read this file when translating **into** German, together with the source-language file. Checker option: `--to de`.

## Variant

Germany, Austria or Switzerland: one choice for the book, recorded in the brief. Swiss Standard German writes ss instead of ß and uses «…» as quotation marks.

## Dialogue and punctuation

- „…“ or »…«, one system for the book.
- A comma after the closing quotation mark: „Ich komme“, sagte er.
- The script flags English quotation marks, the two German systems mixed, and French-style «…» in a text for Germany.

## Dialogue tags

Varied dialogue verbs are accepted in German: follow the original.

## Forms of address

du / Sie, with Sie always capitalized. Record in the brief who uses which form with whom, and where it changes.

## Names and transliteration

Transliterate from non-Latin alphabets with German conventions (Russian Щербина → Schtscherbina).

## Chapter labels

Kapitel 3, Prolog, Epilog.
