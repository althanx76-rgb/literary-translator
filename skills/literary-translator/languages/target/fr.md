# French as the target language (`fr`)

> Status: first draft. Native review welcome (see CONTRIBUTING.md).

Read this file when translating **into** French, together with the source-language file. Checker option: `--to fr`.

## Variant

France or Québec: one choice for the book, recorded in the brief. Vocabulary and some typographic habits differ; the script's spacing checks follow the usage of France, so for Québec follow the publisher's style sheet instead.

## Dialogue and punctuation

- Dialogue in guillemets « … », with a non-breaking space inside them; a change of speaker inside the same exchange is marked with a dash (—).
- A non-breaking space before ; : ! ?
- The script flags dialogue in English quotation marks, normal spaces where a non-breaking space is needed, and missing spaces before ; : ! ? and inside « ».

## Dialogue tags

Varied dialogue verbs are accepted in French: follow the original.

## Forms of address

tu / vous. Record in the brief who uses which form with whom, and where it changes.

## Names and transliteration

Transliterate from non-Latin alphabets with French conventions (Russian Щербина → Chtcherbina).

## Chapter labels

Chapitre 3, Prologue, Épilogue.
